

Requirements Team Page Design

1.  Overview

- This document outlines the requirements or the layout and visuals for the team page
- The overall goal is to have a visually appealing, user-friendly and consistent interface

2. Design for Login Page
Layout
- Centered Login with username//email and password fields
- Sign in button button
- Additional links on the bottom eg. a 'Forgot Password?'

Colours and Typography 
- Background colour: #0B132B (dark navy)
- Input fields in a #295ABB colour with a border
- Button colour will be in a #FFFBF4 or any other matching cream colour
- Font type, Times New Roman
- Text colour, #FFFFFF

Responsive Behaviour 
- Should Scale and Centre properly

3. Design for Team Page 
Layout
- Have what the page is at the top with a small description underneath
- Have 5 spaces in a grid layout for the team cards (the lining can be in a colour that compliments the navy background)
- Team profile card includes:
    Photo (circle)
    Name (in Bold font)
    Role (in smaller font than the name font size)
    Short Blurb (wrap it, if to long, truncate)

Colours and Typography
- The background colour will be the same as the login page, in #0B132B (a dark navy)
- #FFFFFF (white) for the text colour, readable against the dark background
- Have some accent colours to highlight roles or names
- Use same font as the Login Page

Team Cards
- Have space between the cards fro clarity and so it won't look cramped
- Responsive Grid, have 1 card on phone and 3 or more on desktop
- Put in placeholder images for missing photos
- For long blurbs, wrap or truncate with ellipses

4. Edge Cases + Special notes
- For missing photos, put a default placeholder image instead
- Truncate for long blurbs or wrap with max height
- Ensure to have contrast and alt text for images, etc
